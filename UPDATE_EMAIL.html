🔐 Security Architecture

  • Bcrypt Password Hashing - 10 salt rounds with automatic rehashing
  • JWT Authentication - 15-minute access + 7-day refresh tokens
  • Rate Limiting - 5 login attempts/15min, 3 signup/hour
  • Token Blacklisting - Secure logout invalidates all sessions
  • Stripe Webhook Verification - Signature validation on all events
  • CORS & CSP Headers - XSS protection, origin allowlisting
  • Input Validation - Zod schemas on all endpoints
  • Audit Logging - Track all sensitive operations

📦 Technology Stack

  • Framework: Next.js 14+ with TypeScript
  • Database: PostgreSQL with connection pooling
  • Payments: Stripe with webhook processing
  • Email: Resend API
  • Auth: JWT with bcrypt + rate limiting
  • AI: OpenAI (primary), Anthropic Claude, Google Gemini (fallbacks)
  • Testing: Jest with comprehensive coverage

🎯 API Endpoints Summary

Authentication:

  • POST /api/auth/login - User login with password
  • POST /api/auth/signup - New user registration
  • POST /api/auth/logout - Terminate session
  • POST /api/auth/refresh - Refresh access token

Payments:

  • POST /api/payments/intent - Create payment intent
  • POST /api/payments/refund - Process refund
  • GET /api/payments/history - View payment records
  • POST /api/webhooks/stripe - Stripe webhook handler

Plus 25+ additional endpoints for appointments, bookings, and business operations

🚀 Deployment Checklist

  1. Run database migrations (004_create_users_table.sql)
  2. Configure environment variables (.env):
    • DATABASE_URL or DB_HOST/PORT/NAME/USER/PASSWORD
    • STRIPE_SECRET_KEY & STRIPE_WEBHOOK_SECRET
    • RESEND_API_KEY & EMAIL_FROM
    • JWT_SECRET & JWT_REFRESH_SECRET
    • OPENAI_API_KEY (and optionally GOOGLE_GEMINI_API_KEY)
  3. Build: npm run build
  4. Deploy to production
  5. Monitor logs and performance
