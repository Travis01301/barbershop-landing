QUICK START DEPLOYMENT
================================================================================

1. RUN DATABASE MIGRATION:
   psql -U postgres -d barbershop < db/migrations/023_support_ticketing_system.sql

2. CONFIGURE ENVIRONMENT:
   RESEND_API_KEY=re_xxxxx
   CRON_SECRET=your-secret-token

3. SCHEDULE EMAIL PROCESSOR:
   POST /api/support/email-processor every 5 minutes (external cron)

4. ADD COMPONENTS TO PAGES:
   - /support page for customers
   - /admin/support page for admins

5. RUN TESTS:
   npm test -- __tests__/support-*.test.ts

6. DEPLOY TO PRODUCTION:
   npm run build && npm start
